## If your screen still shows the old logo

The server is already serving the new logo (old files give a 404). If your browser still
shows something older, it is your browser's own copy. Three ways to check and fix:

| Step | What to do |
|---|---|
| 1. Confirm the build | Look at the bottom of any page — it says **"Build R34.2 · 30 Sep 2026"**. If it does, you are on the newest build. |
| 2. Desktop refresh | Press **Ctrl + F5** (Windows) or **Cmd + Shift + R** (Mac). |
| 3. Phone refresh | Chrome → **⋮ → History → Clear browsing data → Cached images and files**, or open the link in a private/incognito tab. |

> Since this build the server sends `no-cache` for every page, script and stylesheet, so an
> old copy cannot stay stuck in a browser any more — the next load always gets the new files.
> Images keep their name + version, so they load fast and stay correct.

## Notes

- Passwords are hashed with bcrypt (12 rounds); sessions use an httpOnly cookie (8 hours).
- Every write needs the CSRF header; login is rate-limited (8 failed attempts / 15 min).
- Guests can also open a portal preview at `/#/portal/guest/dashboard` (12 sections).
- Admin can create real accounts: Admin panel → **People Directory** → **+ Add member**.
- The database starts empty by design — no demo members, events, news or applications.
