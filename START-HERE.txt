 YPDC UON  —  ONLY 2 FOLDERS
 1) frontend/   = the complete website  (HTML + CSS + JavaScript)
 2) backend/    = the real server + database (Node.js + SQLite)

A) JUST WANT TO SEE THE WEBSITE (10 seconds, nothing to install)
   Double-click  frontend/index.html  — the website opens.
   (frontend/ypdc-uon-website.html = the whole website in ONE file,
    handy for sending by USB or email.)

B) WANT TO RUN THE SERVER (real login + real database)
   Open a terminal / CMD and run these 3 commands:

      cd backend/server
      npm install            <- once only (needs internet)
      npm run first-run      <- once only: creates .env + the database
                                + one real admin account by itself
      npm start              <- http://localhost:8000

   Admin login  :  http://localhost:8000/#/admin
   email / password / ADMIN_KEY  -> printed on screen at the end of
   first-run and stored in backend/server/.env.
   (Forgot the password? Open the .env file and read it again.)

   NOTE: backend/server picks up the "frontend" folder by itself,
   so keep both folders TOGETHER (exactly as they are here).
   Sandbox shortcut (one command):  bash /home/user/start-local.sh
   → prints the link http://localhost:8000 and runs the server (Ctrl + C to stop).
   No public link is created — everything stays on this machine.

C) WANT A PERMANENT LINK THAT NEVER DIES
   Open DEPLOY-GUIDE.txt — 4 easy steps (GitHub → Render → link ready).
   You get a link like  https://ypdc-uon.onrender.com  which does not depend
   on any sandbox or tunnel. render.yaml is already in this folder, so Render
   sets everything up by itself.
   (Have your own server? Dockerfile + docker-compose.yml are included:
       JWT_SECRET="$(openssl rand -hex 48)" ADMIN_KEY="a-long-key" docker compose up -d --build )

D) NEW USER REGISTRATION (their own account)
   • On the website open  #/login  and click  "Create account".
   • The user fills name + email + role + password and gets their own
     dashboard immediately (no waiting for approval).
   • Every sign-up appears for the admin in  Admin panel -> People Directory
     and in  Activity Log ("Self sign-up (new account)").
   • Admin accounts can never be created from the sign-up form (they need
     the ADMIN_KEY) — that is on purpose.

E) PICTURES ON THE WEBSITE (from the admin dashboard)
   • Admin panel -> Website Content -> "Photos & logo".
   • Upload a homepage hero photo, gallery pictures, or your own logo.
   • The picture is saved in the database and appears on the public website
     straight away (big photos are resized automatically).
   • "Reset" puts the official YPDC logo back.
